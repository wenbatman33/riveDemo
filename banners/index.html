Rive Banners 示範（AI 插畫 + Rive 動畫）

插畫由 codex image_gen（GPT image）生成，動畫與互動用 rive CLI（RML）製作。左：移動滑鼠她會看向你；右：hover / 按 START、點角色會跳。

Neon Anime Girl（540×960）

PlayPals Kids App（1200×630）

State machine + view model：screen（1 首頁 / 2 選單）、hoverStart、downStart、tapBear / tapChick / tapFrog（trigger），並向 host 發出 start／back 事件。
